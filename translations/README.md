# Translations

The course is currently available in English only. Translations are welcome; see `../CONTRIBUTING.md` for the ground rules. Two of them matter most for translated text: the no-em-dash rule applies in every language, and every number in a lesson must still be produced by that lesson's code on the bundled fixtures (code and fixtures are shared across translations; only prose should differ).

If you start a translation, open an issue first so work is not duplicated, and mirror the folder structure under a language folder here (for example `translations/ur/`).
